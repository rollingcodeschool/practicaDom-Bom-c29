Manipulación del DOM & APIs del BOM

El DOM representa la estructura del documento como objetos manipulables en memoria. El BOM nos ofrece comunicación directa con el entorno del navegador (ventanas, temporizadores, resolución).

// Jerarquía básica
window (BOM)
 └── document (DOM)
     └── <html> ...
Selección & Contenido
Seleccionar elementos
  • getElementById('id') → Por identificador único.
  • querySelector('selector') → Primer coincidencia CSS.
  • querySelectorAll('selector') → Colección (NodeList).
Modificar contenido

textContent: Inserta texto plano (más rápido y seguro).

innerHTML: Interpreta HTML (usar con precaución ante XSS).

Gestión de Clases (classList)
Método Acción
.add('clase') Añade si no existe.
.remove('clase') Quita la clase seleccionada.
.toggle('clase') Alterna presencia (quita/pone).
.contains('clase') Verifica presencia (retorna booleano).
