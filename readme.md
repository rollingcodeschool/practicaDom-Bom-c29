# 🚀 Taller Introductorio: DOM y BOM con JavaScript

Proyecto diseñado para estudiantes de programación que dan sus primeros pasos interactuando con el navegador mediante **JavaScript vanilla** y maquetado con **Bootstrap 5.3** en modo oscuro.

---

## 🎯 Objetivos de la clase

- Comprender la diferencia conceptual entre el **DOM** (*Document Object Model*) y el **BOM** (*Browser Object Model*).
- Aprender los métodos esenciales de selección de elementos (`querySelector`, `getElementById`).
- Manipular contenido y atributos en tiempo real (`textContent`, `innerHTML`, `classList`).
- Manejar eventos del usuario (`click`, `submit`).
- Utilizar temporizadores asíncronos provistos por el navegador (`setTimeout`, `setInterval`).
